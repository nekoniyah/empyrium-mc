## Install the Launcher

Downloading one of the files above isn't enough. Those are installers. The file you downloaded for Windows is a zip, it includes a binary and a folder assets such as libraries, images, etc: you need both. Linux in the other hand, only has a binary.

**On Windows:**
1. Extract the .zip files, keep everything and put them a folder.
2. Execute the `empyrium-launcher-Setup.exe` by double-clicking.
3. If it shows warnings, don't worry, it's only because I didn't pay Microslop (I don't need to verify my app to make it work)
4. If it shows command prompts, weird, I don't know why it does that, but anyway it's just installing the launcher.
5. Done! You can find a shortcut on your desktop, or find `empyrium-launcher` in the windows menu.

**On Linux:**
1. Extract the .tar.gz file.
2. Normally, you can double click on the `installer`. If it doesn't, make it executable in the properties of the file (right-click > Properties > "execute as program")
3. Wait a little, it should show something like "electrobun installing..."
4. Done! Done! You can find a shortcut on your desktop, or find `empyrium-launcher` in the windows menu.
